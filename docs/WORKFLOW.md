# צורת העבודה

## מקור האמת

- מוצר: `docs/PRODUCT.md`.
- ארכיטקטורה: `docs/ARCHITECTURE.md` ו־ADR תקפים.
- מצב נוכחי: `docs/STATUS.md`.
- עבודה עתידית: GitHub Issues.
- התנהגות בפועל: הקוד והבדיקות ב־`main`.

כאשר קיימת סתירה, עוצרים ומתקנים את מקור האמת לפני המשך מימוש.

## Definition of Ready

Issue מוכן לעבודה רק כאשר:

- התוצאה הרצויה ברורה.
- קיימים קריטריוני קבלה.
- הוגדר מה מחוץ למשימה.
- הוגדרה רמת סיכון.
- החלטות משתמש מהותיות התקבלו.
- אין חסם חיצוני ידוע.

## זרימת משימה

1. בוחרים Issue במצב `Ready`.
2. קוראים את מסמכי המקור הרלוונטיים.
3. יוצרים branch או Worktree מהגרסה האחרונה של `main`.
4. כותבים תוכנית קצרה ב־Issue או בצ׳אט המקושר.
5. מממשים שינוי אחד ממוקד.
6. מריצים בדיקות מקומיות.
7. מעדכנים מסמכים ו־ADR כאשר נדרש.
8. דוחפים branch ופותחים PR בעברית.
9. סוכן שני מבצע סקירה עצמאית.
10. מתקנים ממצאים ומריצים CI מחדש.
11. ממזגים לפי רמת הסיכון.
12. מעדכנים סטטוס וסוגרים את ה־Issue.

## Definition of Done

משימה נחשבת גמורה כאשר:

- כל קריטריוני הקבלה מתקיימים.
- הבדיקות המקומיות וה־CI עברו.
- נוסף regression test עבור באג כאשר הדבר מעשי.
- אין ממצא חוסם בסקירת הסוכן השני.
- שינוי חזותי כולל Preview וצילום מסך.
- המסמכים משקפים את ההתנהגות החדשה.
- קיימת דרך חזרה לשינוי מסוכן.
- ה־PR מוזג ו־`docs/STATUS.md` עודכן כאשר נדרש.

## שינוי החלטה

### שינוי קטן

ניסוח, הבהרה או שינוי שאינו משפיע על מערכת אחרת יכולים להתעדכן ישירות במסמך המתאים בתוך PR.

### שינוי מהותי

שינוי מוצר, ארכיטקטורה, נתונים, אבטחה, עלות או שירות חיצוני דורש ADR שכולל:

- ההקשר והבעיה.
- ההחלטה.
- חלופות שנשקלו.
- השלכות וסיכונים.
- השפעה על משימות קיימות.
- migration או rollback אם נדרשים.

## רמות סיכון ומיזוג

| רמה | דוגמאות | תנאי מיזוג |
|---|---|---|
| ירוק | תיעוד, בדיקות, refactor קטן | CI + סקירת סוכן שני |
| צהוב | UI, חוקי משחק, dependency, API, migration לא הרסני | CI + סקירה + אישור בעל הפרויקט |
| אדום | מחיקה, Auth, סודות, רישוי, עלות, Production | אישור מפורש + גיבוי + rollback |

## עבודה שנקטעה

אם סוכן אינו מסיים:

- דוחפים את המצב לענף WIP.
- כותבים ב־Issue מה הושלם, מה נכשל ומה הצעד הבא.
- לא משאירים ידע חיוני רק בצ׳אט.
- הסוכן הבא מתחיל מה־Issue ומה־diff, לא מניח שהסיכום מדויק בלי בדיקה.
