# ADR-001 — ניהול AI-first עם GitHub כמקור אמת

- סטטוס: Accepted
- תאריך: 2026-07-30
- בעל החלטה: בעל הפרויקט

## הקשר

בעל הפרויקט אינו מתכנן לכתוב קוד בעצמו. העבודה תתבצע באמצעות Codex ו־Claude Code, התוכנית עשויה להשתנות והפרויקט חייב לשרוד מעבר בין מחשבים, סוכנים ושיחות.

## החלטה

- GitHub ציבורי הוא מקור האמת והגיבוי המרכזי.
- כל שינוי מתבצע דרך Issue, branch ו־Pull Request.
- `main` מוגן; אין Push ישיר.
- `AGENTS.md` הוא חוזה הסוכן המשותף.
- `CLAUDE.md` מייבא את `AGENTS.md`.
- סוכן אחד מממש וסוכן אחר סוקר.
- כל התיעוד והסיכומים לבעל הפרויקט נכתבים בעברית.
- מיזוג מתבצע לפי רמת סיכון.
- סודות נשמרים ב־Bitwarden ולא במאגר או בצ׳אט.

## חלופות

### ניהול דרך שיחות בלבד

נדחה משום ששיחות אינן מקור אמת יציב ואינן מבטיחות המשכיות בין כלים.

### Notion או מנהל משימות נוסף

נדחה בשלב הראשון כדי למנוע פיצול בין מקורות אמת. GitHub Issues והמסמכים במאגר מספיקים.

### עבודה ישירה על `main`

נדחתה משום שהיא מקשה על סקירה, חזרה לאחור ועבודה מקבילית.

## השלכות

- כל משימה דורשת מעט תיעוד לפני מימוש.
- ניתן לשחזר ולהבין את הפרויקט ללא היסטוריית הצ׳אט.
- שינויים מהותיים איטיים מעט יותר, אך גלויים ובטוחים יותר.
- ניתן להחליף סוכן באמצע עבודה ללא אובדן ההקשר המרכזי.

## מעבר וחזרה

שלב 0 מקים את המסמכים, GitHub וההגנות לפני קוד המוצר. אם התהליך כבד מדי, ניתן לפשט תבניות וכללים באמצעות ADR חדש; אין לעקוף אותם בשקט.
