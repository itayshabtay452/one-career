# יומן החלטות

ADR מתעד החלטה מהותית שאמורה לשרוד מעבר בין סוכנים, שיחות וגרסאות.

## סטטוסים

- `Proposed` — הצעה שטרם אושרה.
- `Accepted` — החלטה תקפה.
- `Superseded` — הוחלפה בהחלטה אחרת.
- `Rejected` — נשקלה ולא התקבלה.
