# מילון מונחים

| מונח | הסבר פשוט |
|---|---|
| Git | מערכת ששומרת את היסטוריית השינויים בקבצים. |
| GitHub | העותק המרוחק של הפרויקט, כולל קוד, משימות ו־Pull Requests. |
| Branch | עותק עבודה נפרד של הפרויקט עבור משימה מסוימת. |
| Worktree | תיקייה נפרדת שמאפשרת לעבוד על Branch נוסף בלי להתנגש בעבודה קיימת. |
| Issue | כרטיס משימה שמגדיר מה רוצים, למה ואיך יודעים שסיימנו. |
| Pull Request / PR | הצעה מסודרת להכניס שינוי ל־`main`, כולל בדיקות וסקירה. |
| `main` | הגרסה הראשית והיציבה של הפרויקט. |
| CI | בדיקות אוטומטיות שרצות בכל PR. |
| Preview | כתובת זמנית שמציגה את השינוי לפני שהוא נכנס לגרסה הראשית. |
| Rollback | חזרה בטוחה לגרסה הקודמת. |
| ADR | מסמך קצר שמתעד החלטה חשובה, החלופות והסיבה לבחירה. |
| Dependency | ספריית קוד חיצונית שהפרויקט תלוי בה. |
| PWA | אתר שניתן להתקין ולהרגיש כאפליקציה בטלפון. |
| Seed | ערך התחלתי שמאפשר לייצר שוב את אותה ריצה ואותם אירועים. |
| דטרמיניזם | אותו מצב ואותו קלט מחזירים תמיד אותה תוצאה. |
| Snapshot | תמונת מצב קבועה של נתונים בנקודת זמן מסוימת. |
| Migration | שינוי מתועד במבנה מסד הנתונים. |
| RLS | כללים במסד הנתונים שמגבילים מי יכול לראות או לשנות כל שורה. |
| MCP | חיבור שמאפשר לסוכן להשתמש בשירות חיצוני או בכלי נוסף. |
| Skill | הוראות עבודה חוזרות שהסוכן טוען רק כשהמשימה מתאימה. |
| Regression | מצב שבו שינוי חדש שובר משהו שעבד קודם. |
